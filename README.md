# OIBSIP – Python Programming Internship

## About the Repository

This repository contains the Python projects developed as part of the **Oasis Infobyte Python Programming Internship**.

The projects demonstrate practical knowledge of Python programming, problem-solving, GUI development, API integration, automation, input validation, and security concepts.

## Projects

### Task 1 – Voice Assistant

A Python-based voice assistant that can understand voice commands and perform various tasks such as web searches, weather updates, reminders, email sending, opening websites, and answering general knowledge questions using Gemini AI.

**Technologies:** Python, NLTK, SpeechRecognition, pyttsx3, OpenWeather API, Google Gemini API, Gmail SMTP

**Project:** [View Voice Assistant](Python-Task1-VoiceAssistant/README.md)

---

### Task 2 – BMI Calculator

A command-line BMI Calculator developed using Python. The program accepts weight and height, calculates the Body Mass Index, and classifies the result into standard BMI categories.

**Technologies:** Python, Input Validation, Conditional Statements, Exception Handling

**Project:** [View BMI Calculator](Python-Task2-BMICalculator/README.md)

---

### Task 3 – Random Password Generator

A secure and user-friendly graphical password generator developed using Python and Tkinter. It allows users to customize password length and character types, check password strength, exclude ambiguous characters, copy passwords to the clipboard, and view the last five generated passwords during the current session.

**Technologies:** Python, Tkinter, `secrets`, `pyperclip`

**Project:** [View Random Password Generator](Python-Task3-Random-Password-Generator/README.md)
